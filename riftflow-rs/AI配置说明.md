# AI 配置

默认服务从服务器获取，不再读取 EXE 旁的 ai-config.json，也不在 EXE 中内置默认地址、模型或密钥。旧 JSON 已删除，兼容逻辑已移除。

## 软件内设置

点击右上角星光图标，进入「设置」。留空使用服务器默认配置。自定义时输入接口地址、API 密钥、模型名称并保存，支持 Chat Completions 兼容接口。地址可以是含 /v1 的基础地址，或完整 /chat/completions 地址。

保存后密钥框会清空，修改其他参数时留空会保留原密钥。密钥不会通过读取配置接口回传页面。点击「恢复默认」会删除自定义配置并重新获取服务器默认配置。

自定义配置使用 Windows DPAPI 加密保存在当前用户数据目录的 ai-custom.dpapi，绑定当前 Windows 用户，不用于跨电脑分发。

## 默认配置加密

客户端通过 HTTPS 向 /ai/v1/config 发起 POST 请求，每次独立生成 X25519 临时密钥对，通过 HKDF-SHA256 派生 AES-256-GCM 密钥。客户端校验认证标签、请求随机标识和有效期，拒绝篡改、过期或不匹配的响应。

解密只在 Rust 端完成，默认配置仅在内存缓存五分钟，不写客户端文件，不通过 IPC 返回页面。默认接口、真实模型名和密钥不进入表单。

加密下发不能阻止控制客户端进程的人读取运行时配置，也不能代替服务端代理调用。模型上游继续使用服务器指定的地址，其 HTTP/HTTPS 与配置下发的 HTTPS 属于不同链路。

## 服务端管理

默认配置位于 /opt/riftflow-backend/data/ai-provider.json，权限 0600，供容器用户读取。字段为 url、api_key、model，可选 timeout_seconds、max_tokens。文件不在公告种子或公开静态资源中，不存在明文配置 GET 接口，不应提交到仓库。修改后客户端在缓存到期后重新获取；点击恢复默认会清除本进程缓存。

## 调用与数据

普通问答默认只发送问题和最近三轮对话。战绩总结、周报、单场复盘、阵容建议等使用相应已加载资料，可以展开预览。账号独立分析，最多读取最近 200 条档案，单账号最多 100 条记录。AI 未接入联网检索或实时版本时间线，不自动操作游戏。

选人结束后的自动建议可在设置关闭。开启且配置可用时，进入加载或游戏阶段后每局自动尝试一次，在独立悬浮窗显示；本局关闭后不会再次自动弹出。手动与自动分析都可能产生模型服务费用。
