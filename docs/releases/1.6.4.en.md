# RiftFlow 1.6.4

- Fixed Markdown body text being nearly invisible on dark notice, update and declaration modals. Body and link colors now follow the active application theme.
- Includes the 1.6.3 update-flow fix for restarting from the update dialog, the top-right restart action and automatic replacement.
- Automatic Chinese-to-English notice translation is a server-side admin feature and needs no client update.

Windows 10/11 x64 with WebView2. Builds 1.6.0 and later can check for updates in the app; older builds must update manually. Installation never forces an immediate restart. If the League client runs elevated, run RiftFlow with the same privileges. Champion purchases depend on the current client API and still require user confirmation for each purchase.
