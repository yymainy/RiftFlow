# RiftFlow 1.6.0

- 新增自动更新：启动检查、有新版时提示，支持下载校验、取消和重启安装。
- 新增英雄批量购买入口：仅使用蓝色精萃，展示周免，支持一键排除周免及购买提醒。
- 新增 AI 助手和选人结束后的建议窗口；默认配置由服务器加密下发，自定义配置在本机加密保存。
- 新增对手速览、常用位置分析和搭档表现拆分。
- 修复对局名单、战绩加载与空白显示问题，以及 Mini 窗口本次关闭行为。
- 内置游戏图标，统一构建流程并校验全部窗口和资源。

Windows 10/11 x64，需 WebView2。首次请退出旧程序后手动运行新版，旧版未启用的更新功能无法接收这次安装。后续版本会在软件内提示；更新不会强制重启。客户端以管理员运行时，软件也需要同等权限。英雄商店功能依赖当前客户端接口，真实购买由用户确认。
