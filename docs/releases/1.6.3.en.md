# RiftFlow 1.6.3

- Fixed the release dialog's "restart to update" action exiting without replacing files or restarting. The verified updater now starts before that direct exit.
- When upgrading from 1.6.0–1.6.2, if that dialog restart still does nothing, click the update icon in the top-right corner and choose "Restart now"; alternatively, exit the app and run the new version manually.
- This release only contains the update-flow fix; champion shop behavior is unchanged from 1.6.2.

Windows 10/11 x64 with WebView2. Builds 1.6.0 and later can check for updates in the app; installation never forces an immediate restart. If the League client runs elevated, run RiftFlow with the same privileges. Champion purchases depend on the current client API and still require user confirmation for each purchase.
