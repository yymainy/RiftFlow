# RiftFlow 1.6.2

- Fixed Blue Essence balance reads in the champion shop by using the client's current `lol_blue_essence` wallet field, keeping legacy `IP` fallbacks and removing the older login-wallet endpoint that returns 404.
- Fixed HTTP 400 responses and empty champion lists on some clients by fetching the store catalog without build-specific query parameters and filtering locally. Rotation, ownership and warnings remain visible when prices or balance are unavailable, and purchases stay blocked.
- Added a warning banner; errors now show the failing endpoint and HTTP status instead of `[object Object]`; the purchase button stays disabled until the balance is confirmed.
- Added regression coverage for wallet shapes, zero and string values, currency confusion, simulated purchases and a read-only real-client wallet check.

Windows 10/11 x64 with WebView2. Builds 1.6.0 and later can check for updates in the app; installation never forces an immediate restart. If the League client runs elevated, run RiftFlow with the same privileges. Champion purchases depend on the current client API and still require user confirmation for each purchase.
